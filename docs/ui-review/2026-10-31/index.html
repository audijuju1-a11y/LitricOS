LitricOS UI review — 2026-10-31

42 screens, each 1280×800 px. Forty-one are regenerated through the shipping views::draw composition by litric-shell/examples/frame_dump.rs. The forty-second is a real third-party Linux application — Ubuntu Weston 13 weston-simple-shm — installed and launched through litric-sysd over a Unix socket, mapped as a Wayland window, and composed by the same views::draw path in the S82 real-socket e2e. Blue marks the S82 screen; the S85 install entry, S86 uninstall dialog and S87 dock pin are marked separately.
